## Project Title

**MailMind – NLP-Based Email Intelligence System**

## Project Overview

MailMind is an NLP-based email intelligence application powered by Google Gemini LLMs. It analyzes emails and converts unstructured content into actionable insights.

## Key Features

- **Email Classification** – Categorizes emails into Work, Personal, Promotional, Finance, Support, or Other.
- **Urgency & Priority Detection** – Identifies the urgency and priority of emails.
- **Email Analysis** – Generates summaries, sender intent, and sentiment.
- **Action Item Extraction** – Extracts tasks and explicitly stated deadlines.
- **Task Tracking** – Provides an interactive checklist with completion progress.
- **Smart Reply** – Generates context-aware email replies using different tones.
- **Demo Mode** – Allows project demonstration without making API requests.
